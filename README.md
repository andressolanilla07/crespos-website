# Crespos Sala de Belleza

Repositorio privado para la documentación y el futuro website de Crespos Sala de Belleza.

**Estado:** levantamiento y documentación inicial. El website todavía no está implementado.
**Fecha:** 2026-10-11. **Rama prevista:** `main`.

## Propósito y alcance

Crear un portafolio del salón que muestre su trabajo, servicios y equipo, y facilite el contacto por WhatsApp e Instagram. El MVP contempla un carrusel de promociones y servicios, seis servicios con precios publicados fijos y cuatro profesionales provisionales.

Los nombres, descripciones, valores y moneda de los servicios están pendientes de validación. La composición del equipo, nombres, fotografías y especialidades también requieren confirmación. La tienda y los servicios adicionales permanecen pendientes de definición.

## Decisiones técnicas

HTML5, CSS3, JavaScript y JSON; sin framework, backend ni base de datos en el MVP. El desarrollador realizará aproximadamente 2–3 actualizaciones mensuales. No habrá panel de administración en este alcance.
